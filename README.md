# Платформа Ярослава Кирдуна

Личный сайт: работы, пакеты с ценами, калькулятор сметы, бесплатное демо и заказ через бота @KirdunSupportBot. RU (`/`) и EN (`/en/`).
Чистый HTML/CSS/JS, хостинг на GitHub Pages. Страницы собираются одной командой из данных.

## Как всё устроено

- `assets/js/config.js` и `assets/js/data.js`: все данные (контакты, условия, услуги, цены калькулятора, пакеты, проекты, FAQ, дневник).
- `assets/js/calc.js`: формула сметы и ссылка в бота. Ей же пользуются пакеты, калькулятор, сборщик и бот (бот проверяет это тестом).
- `tools/build.mjs` + `tools/strings.mjs`: собирают `index.html`, `en/index.html`, `sitemap.xml`, `robots.txt`. Весь текст, цены, FAQ и JSON-LD попадают прямо в HTML, поэтому поисковик видит их без JS, а первый экран рисуется сразу.
- `assets/js/main.js`: только интерактив поверх готовой страницы (вкладки цен, валюта, калькулятор, демо Кордона, меню).

Все кнопки «Заказать», «Получить демо» и калькулятор ведут в бота с параметрами:
`https://t.me/KirdunSupportBot?start=o_<услуга>_<кол-во>_<опции>_<флаги>` (например `o_bot_0_pay-crm_e`), `demo`, `site`.
Бот показывает ту же смету, создаёт заявку и шлёт Ярославу карточку. Личный профиль на сайте не светится.

## Как поменять данные

1. Правишь `assets/js/config.js` или `assets/js/data.js`.
2. Пересобираешь страницы:
   ```bash
   node tools/build.mjs
   ```
3. Если менялись цены или услуги, обнови каталог бота: в папке `hub-bot` выполни `npm run sync`, затем `npm test` и деплой бота.
4. Коммит и пуш: GitHub Pages обновит сайт за минуту.

Что где в данных:
- `PACKAGES`: пакеты на вкладках «Цены». Цена и срок не пишутся руками, их считает `calc.js` из `order` (опции калькулятора).
- `PROJECTS`: портфолио. `featured: true` — большая карточка, `facts` — 2–3 цифры. Картинка 960×600 в `assets/img/` плюс уменьшенная `<имя>-640.webp`.
- `DIARY`: дневник. Новые записи сверху, только реальные события.
- `config.goal.show`: счётчик заработка (выключен: нулевой счётчик отпугивает).
- `config.payments.npdRegistered: true` после регистрации самозанятым: появится «выдаю чек».

Реквизиты карты и ЕРИП, токены и ключи сюда **не писать**: сайт публичный. Реквизиты задаются в боте командой `/setpay` и уходят клиенту только по кнопке.

## Запустить у себя

```bash
python -m http.server 8773 --directory platform
```

Открыть http://localhost:8773 и http://localhost:8773/en/

Проверить, что страницы собраны из свежих данных (код выхода 1, если нет):

```bash
node tools/build.mjs --check
```
