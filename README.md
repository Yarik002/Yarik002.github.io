# Платформа Ярослава Кирдуна

Личный сайт: проекты, услуги с ценами, калькулятор сметы и заказ в Telegram. RU и EN.
Чистый HTML/CSS/JS без сборки, хостинг на GitHub Pages.

## Как поменять данные

Всё содержимое лежит в двух файлах, вёрстку трогать не нужно.

`assets/js/config.js`
- `telegram`, `email` — куда приходят заказы.
- `openForOrders` — плашка «Принимаю заказы».
- `goal.earned` — сколько заработано, обновлять после каждой оплаты. `goal.show: false` прячет полосу.
- `payments.npdRegistered: true` — после регистрации самозанятым (появится «выдаю чек»).
- `payments.erip` — код услуги в ЕРИП, когда подключишь «Экспресс Платежи».
- `payments.starsBot` — username бота, если будешь принимать Stars.
- `rates` — примерные курсы для переключателя BYN / ₽ / $.

Реквизиты карты, токены и ключи сюда **не писать**: сайт публичный.

`assets/js/data.js`
- `PROJECTS` — портфолио. Новый проект = новый объект (скопируй любой и поменяй). Картинку 960×600 в `assets/img/`.
- `SERVICES` — услуги и цены «от».
- `CALC` — цены калькулятора: база, опции, доплата за страницу/ролик/сайт.
- `DIARY` — дневник пути. Новую запись добавлять **сверху**, только реальные события.
- `PROCESS`, `FAQ` — шаги работы и вопросы.

## Запустить у себя

```bash
python -m http.server 8773 --directory platform
```

Открыть http://localhost:8773

## Опубликовать изменения

```bash
git add -A && git commit -m "Обновил проекты" && git push
```

GitHub Pages обновит сайт за минуту.
